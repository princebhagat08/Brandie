# Brandie

## Getting Started

Follow the steps below to run the project locally.

### 1. Clone the Repository

Clone the project using the repository link provided below:

```bash
git clone git@github.com:princebhagat08/Brandie.git
```

### 2. Install FVM

This project uses:

```
Flutter Version: 3.38.7
```
Use **FVM (Flutter Version Management)**.


### 3. Open an Emulator or Connect a Device

Start an Android/iOS emulator or connect a physical device before running the application.

### 4. Install Dependencies

Navigate to the project directory and run:

```bash
fvm flutter pub get
```

### 5. Run the Application

Launch the app using:

```bash
fvm flutter run
```

---

## Theme Support

The application supports both **Light Mode** and **Dark Mode**. It automatically adapts to the device's system theme settings, providing a seamless user experience without requiring any manual configuration.

## Assumptions

- FVM is installed and configured on the development machine.
- Flutter SDK version **3.38.7** is used for consistent builds.
